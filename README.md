# File-Drop-X
AWS-powered Smart File Converter Physical Drop Box using Raspberry Pi for automated file conversion and secure file management.

## Project Overview

The Smart File Converter Physical Drop Box is a kiosk-based system that allows users to upload files through a USB device and convert them into different formats. The system integrates Raspberry Pi hardware with AWS cloud services to provide secure, fast, and automated file conversion.

Users can select a file, choose the desired output format, and receive the converted file without requiring technical knowledge or complex software installations.

---

## Problem Statement

Many users need file format conversion services but may not have access to specialized software or reliable internet connectivity. Existing solutions often require manual installation, online accounts, or technical expertise.

The Smart File Converter Physical Drop Box aims to provide an easy-to-use physical kiosk that performs file conversions securely and efficiently using cloud-based processing.

---

## Objectives

- Develop a physical file conversion kiosk.
- Support multiple file format conversions.
- Integrate Raspberry Pi hardware with AWS cloud services.
- Provide a simple and user-friendly interface.
- Ensure secure file handling and storage.
- Automate file conversion processes.
- Deliver converted files quickly and accurately.

## System Workflow

1. User inserts a USB drive.
2. User selects a file.
3. User chooses the desired output format.
4. File is uploaded to AWS.
5. AWS processes the conversion.
6. Converted file is stored securely.
7. User downloads the converted file.
